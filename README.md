# 消费者用药风险线索分诊

把因健康广告产生的用药风险线索分级、干预并保护隐私。

## 参与方与事实

主要参与方包括消费者服务人员、药师或医学顾问、平台安全人员、监管联络人员。领域资料记录以下事实：

- 虚假医疗承诺可能让患者擅自停药
- 消费者健康素养差异会放大仿冒专业身份的风险
- 平台需要识别并处置可能造成实际伤害的传播

## 业务边界

- 紧急程度
- 产品与主张关联
- 隐私分层
- 转介责任
- 回访期限

当前资料按以下边界组织：

- 线索受理
- 风险分诊
- 干预建议
- 转介回访
- 群体影响

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/safety_context.py` 负责读取和校验资料。

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

命令只读取仓库内文件，不需要连接外部业务系统。
